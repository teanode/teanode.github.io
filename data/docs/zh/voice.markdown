按下聊天抽屉里发送按钮旁边的电话，开口说话。你说的话一边说，一边经过你的服务器传到提供方的
转写那里；你每说完一段，就作为普通的一轮发给你的代理，而回答一边写，一边读给你听。这就是和你的
代理通一次电话，在仪表盘的任何一页上，笔记本和手机上都行。

## 通话是什么样子

你说话的时候，输入框换成五根随你的声音起伏的竖条，旁边是到目前为止听到的话，还有一个用来挂断的
红色听筒。对话一直显示在上面，所以说过的话之后还能读到，你也可以挂断电话接着打字。

**它马上就回应。** 对面立刻回话，通话才像是活的。查东西之前，代理会先说一两句（「我查一下」），
不让你干等着；你说得很长的时候，它会像听的人那样发出一些简短的应和声。如果运维者为通话配置了一个
更快的模型，就由那个模型来回答，遇到难的问题（建议、计算、要推好几步的事）再交给打字时用的那个
模型，并且先说一声。

**它是写给耳朵听的。** 说出来的一轮会告诉代理，这些话是转写出来的，名字可能听错了；还会要它先说
答案，用几句短句，不要表格和代码，数字按人平常的说法来说，在根据一个可能听错的名字、金额或日子
行动之前先确认一遍。代码块、网址和建议回复的按钮不会被读出来。

**你可以插话。** 在它回答时开口，声音会立刻低下去，你继续说它就停下。代理会被告知你听到了回答的
多少，所以它绝不会以为你听到了你没听到的。点一下竖条可以把回答打断。扬声器按钮让这台设备不再朗读
回答，但不挂断电话。

**打字能做的它都能做。** 说出来的一轮可以引导一轮正在跑的对话，可以回答一张开着的提问卡片，也能
用到你代理的每一个工具。确认卡片会被读成「需要你在屏幕上批准」，因为用声音批准还没有做好。

**用你选的声音，或者它的。** 每个人在自己代理的设置里挑选朗读回答所用的「说话的声音」，可以先试听，
也可以在通话中让代理换一个。

## 回声

在手机上，扬声器就挨着麦克风，回答会被录回去，当成是你在说话。抽屉会请浏览器打开回声消除；在这
之上，它还会摸清回答传回来有多响，只把明显比这响得多的声音算作你，并丢掉任何重复刚刚播放的话的
内容。戴耳机就完全没有这个问题。

## 打开它

语音由运维者来打开，在 `agent.voice` 里，可以在服务器页面的「代理」标签上，或者用
`teanode settings`：

    teanode settings set agent 'voice:={"enabled":true}'

它用一个种类为 `openai` 的提供方，密钥从不离开服务器：抽屉和你的服务器说话，你的服务器再和提供方
说话。转写模型、语音合成模型、默认的声音、判断一个人说完了的停顿时长，以及一个可选的、通话专用的
更快的模型，都在[配置](/doc/configuration#agentvoice)里。转写和语音合成像任何一次模型调用一样，
记在代理当天的用量上，种类是 `voice`，所以运维者的限额同样适用。

## 它还不会做的

- 用声音批准一张确认卡片。
- 连接断了之后继续听：抽屉会说它停了，你再按一次电话就行。
- 在浏览器扩展的抽屉里通话，那个页面有它自己的麦克风权限。
